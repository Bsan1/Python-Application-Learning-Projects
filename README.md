# CNG445 Software Development with Scripting Languages

Three Python assignments that progress from command-line data processing to network programming and full-stack web development.

## Assignments

### Assignment 1 - Task Management Analyser

A command-line Python application that parses task-management logs with regular expressions and builds objects for members, managers, teams, and tasks. It generates reports for manager expertise, urgent work, team workload, busiest members, and task properties.

Main topics: Python fundamentals, object-oriented programming, regular expressions, file processing, command-line arguments, dictionaries, and data visualization.

### Assignment 2 - Bookstore client-server application

A TCP-based bookstore system with separate cashier and manager interfaces built with Tkinter. The server manages authentication, inventory, transactions, single-use discount codes, and sales reports using semicolon-delimited text files.

Main topics: sockets, client-server protocols, GUI programming, file-backed data, transaction processing, and concurrency concepts.

### Assignment 3 - Local Event Advertisement Portal

A Flask and SQLite web application for publishing and finding campus events. It includes registration, login and session management, user profiles, event announcements, society management, keyword search, event details, and role-based admin access.

Main topics: Flask, SQLite, HTML, CSS, JavaScript validation, database-backed web forms, authentication, and server-side rendering.
